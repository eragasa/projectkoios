# Owner-repository technical debt convention

The [project-wide technical-debt boundary](../index.md) keeps durable
observation separate from architecture decisions and execution records. This
convention applies to every Project Koios repository that records technical
debt.

The convention is guidance for keeping evidence useful and authority explicit.
It is not a serialized schema, mandatory heading set, task workflow, or approval
process.

## Immediate responsibility

This index identifies only its direct child responsibilities. It does not
catalog owner repositories, debt areas, or descendant records.

| Direct child | Immediate responsibility |
|---|---|
| [Ownership](ownership.md) | Defines owner-local placement, immediate indexes, cross-repository boundaries, and public-record safety. |
| [Records](records.md) | Defines when to record debt and the evidence, impact, constraints, investigation, and exit guidance each record covers. |
| [Architecture and execution](architecture-and-execution.md) | Separates observations from architecture decisions, authorization, coordination, review, and implementation evidence. |
| [Example](example.md) | Shows a concise generic observation without claiming that its names or paths exist. |
